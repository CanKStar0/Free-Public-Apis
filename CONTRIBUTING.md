# Contributing

This repository publishes a browsable index generated from the canonical catalog in [CanKStar0/Free-API](https://github.com/CanKStar0/Free-API). The source repository's catalog workflow synchronizes this README after catalog changes.

- To add, remove, rename, or recategorize an API, propose the change in the source repository.
- Do not edit API rows or category links in this repository by hand; automation regenerates them from the source catalog.
- Report a broken FreeAPI detail link or a sync problem with a focused issue in this repository.
- API providers' documentation and terms are authoritative and may change independently of this index.
